# Kutira-Kone 

## Overview

Kutira-Kone is an Android application developed to address the growing issue of textile waste generated by home-based tailors, boutique owners, and small garment businesses. Large quantities of usable fabric scraps are often discarded despite having potential value for artisans, craft makers, students, and small-scale entrepreneurs. The application creates a digital platform that enables users to share, exchange, and discover excess fabric materials, promoting sustainability and supporting self-employment opportunities.

## Problem Statement

Many home-based tailors and boutique owners generate excess fabric remnants during garment production. These leftover materials are frequently treated as waste and discarded. At the same time, hobbyists, designers, students, and handicraft creators actively seek small fabric pieces for patchwork, quilting, doll making, embroidery, and other creative projects. The lack of a dedicated platform connecting these two groups results in resource wastage, increased environmental impact, and missed economic opportunities.

## Solution

Kutira-Kone provides a simple and user-friendly mobile platform where users can list available fabric scraps, upload images, browse available materials, and connect with interested individuals. By enabling fabric reuse and exchange, the application promotes sustainable practices while creating opportunities for income generation and community collaboration.

## System Architecture

The application follows a modular Android architecture where the presentation layer interacts with business logic and local data storage. User interactions are processed through Android Activities and UI components, while Room Database handles structured data storage and retrieval. CameraX is used for image capture and management, ensuring a smooth user experience.
